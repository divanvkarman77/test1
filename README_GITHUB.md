# Электричество 2.1

Красивый мобильный калькулятор электроэнергии для Android.

- Название: **Электричество**
- Версия: **2.1**
- Новая иконка с лампочкой и молнией
- Интерфейс для экрана телефона
- День/ночь, тарифы, показания, стоимость
- Обратный расчёт кВт⋅ч по сумме
- Сохранение тарифов
- Светлая/тёмная системная тема
- Автоматическая сборка APK через GitHub Actions

Загрузка в GitHub: **Actions → Build APK → Run workflow**.
После успешной сборки скачайте Artifact **Elektrichestvo-2.1-debug**.
